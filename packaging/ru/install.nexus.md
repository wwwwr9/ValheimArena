## Установка

1. Требуется **BepInExPack Valheim** ({BEPINEX_URL}); если он уже установлен вместе с другими модами,
   этот шаг пропускается.
2. Архив мода распаковывается в папку игры (Steam → Valheim → Управление → Просмотреть локальные файлы) так,
   чтобы получился путь `Valheim\BepInEx\plugins\ValheimArena\ValheimArena.dll`; Vortex устанавливает архив
   самостоятельно.
3. Всем игрокам, которые участвуют в бою или находятся рядом с ареной, нужна одна и та же версия мода.
   Мод желательно поставить и на сервер мира (см. раздел «Зона симуляции»).
4. После запуска игры в `BepInEx\LogOutput.log` появляется строка
   `Valheim Arena {VERSION} loaded: N patches, 0 errors`, а при русском интерфейсе
   `… загружен: патчей N, ошибок 0`.

Для обновления новый архив распаковывается поверх прежнего. Перед удалением арену следует свернуть во всех
мирах, где она развёрнута, после чего удаляется папка `BepInEx\plugins\ValheimArena`.

Настройки и данные хранятся в `BepInEx\config\`, и ни обновление, ни удаление мода их не затрагивают:
- в `{GUID}.cfg` записаны язык интерфейса (`Language`: English по умолчанию, Russian или Auto, следующий языку
  игры), клавиши, масштаб интерфейса в виде множителя к автоматическому (окна подстраиваются под высоту экрана,
  и при 1080p множитель равен 1) и чувствительность мыши;
- в `ValheimArena\settings.json` записаны все настройки арены и состав; файл сохраняется при закрытии окна;
- в `ValheimArena\profiles\<прототип>\<имя>.json` лежат профили существ из редактора;
- в `ValheimArena\scenarios\<имя>.json` лежат сохранённые сценарии, то есть состав и правила арены.
