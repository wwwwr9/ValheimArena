# Valheim Arena

{INTRO}

The interface is available in English, the default, and in Russian; the language is switched with the
EN / RU / Auto buttons at the top of the arena menu (F7) or with `Language` in the config. Documentation in
Russian is in README.ru.md inside the archive.

## Installation

1. Install **BepInExPack Valheim** ({BEPINEX_URL}) unless it is already present.
2. Extract this archive into the Valheim folder (Steam → Valheim → Manage → Browse local files) so that the
   result is `Valheim/BepInEx/plugins/ValheimArena/ValheimArena.dll`. Vortex installs the archive on its own.
3. Make sure everyone at the arena has the same version of the mod.
4. Start the game; `BepInEx/LogOutput.log` then shows `Valheim Arena {VERSION} loaded: N patches, 0 errors`.

To update, extract the new archive over the old one. To uninstall, first close the arena in every world where
one is deployed, then delete `BepInEx/plugins/ValheimArena`. Settings, profiles and scenarios in
`BepInEx/config` are kept.
