# Valheim Arena

{INTRO}

The interface is available in English, the default, and in Russian; the language is switched with the
EN / RU / Auto buttons at the top of the arena menu (F7) or with `Language` in the config. Documentation in
Russian follows at the end of this page.

## Installation

The mod installs through r2modman or Thunderstore Mod Manager, which install BepInExPack Valheim automatically.
Everyone at the arena needs the same version of the mod, which is easiest to ensure by sharing a mod manager
profile code. On start, `BepInEx/LogOutput.log` shows `Valheim Arena {VERSION} loaded: N patches, 0 errors`.
